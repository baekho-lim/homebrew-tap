# Homebrew Tap

Homebrew formulae for tools by baekho-lim.

## Install

```bash
brew tap baekho-lim/tap
brew install secret-wallet
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [secret-wallet](https://github.com/baekho-lim/secret-wallet) | Keychain-based credential manager for AI agents |
